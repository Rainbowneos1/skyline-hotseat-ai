# Skyline 天际线 · 网页版

**双击 `index.html` 就能玩**——不需要服务器、不需要联网、不装任何东西。

## 三种模式

- **热座**：2–4 人共用一台设备，轮流操作（可开"换人提示"）
- **人机**：每个座位单独选「人类 / AI」，AI 有六档难度（入门→大师）
- **双机演示**：全部座位交给 AI，两边的难度可以不同，支持慢/中/快/暂停

## 页面

- `index.html` —— 游戏
- `rules.html` —— 规则（含骰子概率分布）
- `about.html` —— 声明：去背景化实现、无关联无授权、使用了 AI 技术

## 其它

- 本目录是**扁平**的：所有脚本与样式都在根目录，没有任何子目录或外部请求
- 骰子与楼塔全部由代码绘制，不含任何原版素材
- 设置（人数/座位/难度/种子/速度）存在浏览器本地
- 小技巧：网址后加 `?seed=12345` 可以复现同一副骰子

本目录由 `tools/build_web.py` 从 `web/` 生成，请勿直接改这里。
